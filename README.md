# UB-Mager Docs

> Bruno API collection for the UB-Mager ride-hailing platform.

## Setup

1. Install [Bruno](https://www.usebruno.com/)
2. Open this folder as a collection
3. Select environment: `Local` or `Development`
4. Start with `Auth > Login` to get access token

## Collections

- **Auth** — Register, Login, Refresh, Logout
- **Passenger** — Profile, ride booking, history, rating
- **Driver** — Registration, status, location, ride lifecycle, earnings
- **Admin** — Dashboard, driver management, ride management
- **Analytics** — Revenue, heatmap, demand prediction
- **WebSocket** — Connection reference
